This project uses Python, pandas, and matplotlib to explore a retail sales dataset.<br>
It calculates total sales, profit, order count, units sold, average order value, and profit margin.<br>
It also summarizes sales by month, category, region, product, and payment method.<br>
<br>
The script prints its findings and saves summary tables and charts in an analysis_output folder.<br>
A setup guide with installation and run instructions is included in README_setup.txt.<br>
